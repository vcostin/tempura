    Techniques in the pan

    Sprint

    Warm-up, easing into a hard start

    15m focus / 3m break

    Tiny intervals to get moving. Use it to break inertia, dabble into a hard task, or rebuild attention after a distraction.

    Work rhythms for the desk — not a diagnosis, and not medical advice.

    Rust holds the clock

    The countdown belongs to the native side, so a hidden window or a machine that slept does not cheat the session. Start, pause, skip, reset, stop — the tray tooltip stays live.

    Close it. It stays.

    Tempura lives in the system tray. Closing the window hides it; quitting is a deliberate choice from the tray or Settings. Launch at login if you want it waiting with the kettle.

    Nothing leaves the board

    Presets, settings, and history sit in local SQLite under the app data directory. No accounts, no cloud, no sync — MIT licensed, yours to inspect.

    After it lands

    Linux
    AppImage: chmod +x the file, then run it. Debian: install the .deb. Fedora and openSUSE: the .rpm. You may need FUSE for AppImage.
    Windows
    SmartScreen may warn on the first run — the build is unsigned. More info → Run anyway, or use the MSI.
    macOS
    Gatekeeper may block an unsigned app. Right-click the app → Open. Apple Silicon and Intel each have their own disk image.
